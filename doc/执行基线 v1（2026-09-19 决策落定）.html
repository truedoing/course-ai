二、组织规模与性质（重大调整）

  • 性质：社团自愿 / 兴趣小组，非校方行为，定位"实验性质"。
  • 规模很小：Python 班 7–8 人即可，不是大营。总盘是高质量小团队。
  • 遴选与运转：只收高质量 + 强自驱力学生；强调自组织，自驱力弱不收。
  • 精力红线：张同时承担 教学 + 体系设计 + AIGC/FDE 双边事项。不靠人海，靠少数能自驱的人，否则极耗精力。

注：这与早期"招 45-60 留 18-20"的默认参数冲突，以本轮为准。招募门槛从"数量"改为"质量+自驱"。

三、主副配合（解决精力分配）

张 · 全局 + 基础技术

版块侧重：FDE
  • 全局设计与体系架构
  • 基础技术底座（调接口 / 批处理 / Git / 读报错）
  • FDE 方向推进（需求澄清、部署交付、沉淀复用）

董老师 · AIGC 应用层

同校计算机系，教 UI；定位"AI 内容视觉资产架构者"
  • 侧重 AIGC 应用层（一致性、质检、资产与规范）
  • 标准 / 验收由她，管线 / 底座由张
  • 让张得以把精力倾斜到 FDE

与家属线此前结论一致：她定"什么算合格"，张做"怎么批量跑"——不替她定义视觉标准，否则内核作废。
