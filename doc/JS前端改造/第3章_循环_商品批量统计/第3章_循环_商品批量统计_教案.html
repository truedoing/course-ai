一、教学目标

维度目标
知识for / for...of / while 三种循环；数组 length、索引、遍历；累加器模式；用对象做分组计数；极值与均值。
能力独立写出 aggregate(products)，从商品数组算出种类 / 库存 / 分类 / 最贵最便宜 / 均价；把结果渲染到首页统计条。
素养理解「一次写好、处处复用」的母体一致性；习惯「先跑通自检再提交」的 AI 落地执行者工作流。

二、重难点

  • 重点：循环遍历数组 + 累加器（sum / count）；分组统计（对象当计数桶）。
  • 难点：① 对象当桶时「桶不存在先给 0」(cats[c] || 0)；② 极值初始值设 ±Infinity 而非 0；③ 均价四舍五入保留两位。
  • 易错：while 忘记自增 → 死循环；混淆 stock（库存）与 price（价格）。

三、教学过程（时间分配以 git 已顺完为前提；若未顺完，跳过演示直接布置自学）

环节时长内容与教学设计
① git 闭环收尾随堂确认每位同学已 fork→clone 模板、改店名/商品、push 成功并看到自己的小店。这是「可视化闭环成果感」的关键，优先级最高。
② 导入（1 分钟）1'提问：首页那条统计条（商品种类 / 库存 / 分类）怎么算出来的？引出「要遍历每一条商品 → 循环」。
③ 三种循环（精讲）8'用库存总和一个例子，分别写 for / for...of / while，强调结果等价、写法不同。板书三版代码。
④ 分组统计（难点突破）6'演示「对象当计数桶」：cats[c] = (cats[c]||0)+1。对比「写 5 个 if 判断分类」的低效写法。
⑤ 母体函数 aggregate（演示）6'把上面串成 aggregate(products)，强调函数名/签名全程不变，期末综合案例直接复用。
⑥ 学生跑通 + 自检余下打开切片代码，node 跑一遍，看到「✅ 自检通过」。改 1 个商品数据，自检仍通过 → 理解「数据驱动」。
⑦ 收尾 & 顺延预告2'讲清：今天先看懂 + 跑通；完整练习、变式、渲染到页面放到下节课。课后按《作业说明》自己写。

四、核心代码（板书 / 投影）

// 母体函数：与期末综合案例（项目七 renderProducts 数据驱动渲染汇合处）同名同签名 function aggregate(list) { const r = { total:list.length, stockSum:0, priceSum:0, cats:{}, maxPrice:-Infinity, minPrice:Infinity }; for (const p of list) { r.stockSum += p.stock; r.priceSum += p.price; r.cats[p.category] = (r.cats[p.category] || 0) + 1; if (p.price > r.maxPrice) r.maxPrice = p.price; if (p.price < r.minPrice) r.minPrice = p.price; } r.catCount = Object.keys(r.cats).length; r.avgPrice = Math.round(r.priceSum / r.total * 100) / 100; return r; }
