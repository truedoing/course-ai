# DESIGN.md · 第3章 循环·商品批量统计（教师版 PPT）

## 风格：学术风（教学课件·理工）
画布 1280×720，安全边距左右 40。内容页 C 区铺满，禁用大留白撑版面。

## 色彩（≤4 主 hex + 文本/线框）
- 藏蓝 `#0E3F8C`（顶条、重点、章节）
- 主蓝 `#1E4FA8`（编号、强调）
- 浅蓝底 `#F0F5FC`（卡片底、表头浅底）
- 警示红 `#D9534F`（关键词/易错提示，单页 ≤3%）
- 文本 `#1A2230` / 辅助 `#4A5568`；线框 `#D6DCE5`；背景 `#FFFFFF`

## 字体（≤2 家族）
- 中文/正文：思源黑体系（系统默认黑体），标题 32–36px Bold，正文 22–26px Regular。
- 代码：等宽（CodeBlock 默认），fontSize 13–14。
- 卡内标题 24–28px Bold。

## 母版
- A 区：藏蓝顶条 y 0–88，含白色章节名 + 右侧页码。
- C 区：y 96–648，内容铺满 1200×≥476。
- D 区：y 660–700，左「JS 前端 · 项目三」灰字，右页码 NN/08。
- 内容页统一顶条 + 页脚，位置全篇一致。

## 密度基线
- 内容页 C 区累计高 ≥476px，元素不挤中央 60%。
- 代码页：CodeBlock 占左 ~58%，右侧要点卡 ≥22px。
- 每页 ≥3 类组件（Box/Text/CodeBlock 或 Table），层次 ≥3。

## 配图
- 无外采图，以 CodeBlock（代码证据）与 Table 为 L1 主视觉。
- 禁 3D / 卡通 / 营销插画 / 装饰渐变大图。
