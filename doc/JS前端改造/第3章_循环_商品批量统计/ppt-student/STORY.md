# STORY.md · 第3章 案例实训·商品批量统计（学生版 PPT）

## ① 用户意图对齐
- **目标受众**：高职 JS 前端课学生，课堂投影 + 课后自学，用于独立完成「项目三·循环」实训。
- **核心目标**：学生照着做就能给「某某小店」加上统计条；理解循环遍历与 aggregate；跑通自检、提交。
- **PPT 长度**：8 页（封面 + 6 任务/步骤 + 收尾）。Hero 2 页（封面、收尾），占比 25%。
- **视觉调性**：学术严谨、蓝白克制；纯任务 + 参考代码 + 步骤 + 自检，**不含教学设计**。
- **内容边界**：只给「做什么 / 怎么做 / 怎么查 / 怎么交」；不出现教师视角的教学目标与重难点讲解。

## ② 布局骨架
- 8 页，无目录/章节扉页（学生实训流，直接任务流）。
- Hero：P1 封面、P8 收尾。间隔 ≥1 supporting 页。
- 非对称版式 ≥5/6 内容页（左大code+右文字 / 非对称双栏 / 左标题+右内容）；对称仅 P6 清单卡（1 页）。
