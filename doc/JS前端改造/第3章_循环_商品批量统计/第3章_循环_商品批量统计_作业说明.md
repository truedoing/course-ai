## 3. 第二步：自己写出 aggregate（课后主任务）
切片里已经给了**参考实现**。你的任务：遮住参考，照着课堂讲的 4 个知识点，自己写一遍。

参考骨架（先把这三个点想清楚）：
1. **循环遍历**：`for (const p of list)` 拿到每一件商品的 `p`
2. **累加器**：`stockSum += p.stock`（库存往上加）
3. **对象当桶**：`cats[p.category] = (cats[p.category] || 0) + 1`（分类计数）

```js
function aggregate(list) {
  const r = { total: list.length, stockSum: 0, priceSum: 0, cats: {},
              maxPrice: -Infinity, minPrice: Infinity };
  for (const p of list) {
    r.stockSum += p.stock;
    r.priceSum += p.price;
    r.cats[p.category] = (r.cats[p.category] || 0) + 1;   // 桶不存在先给 0
    if (p.price > r.maxPrice) r.maxPrice = p.price;        // 别用 0 当初值！
    if (p.price < r.minPrice) r.minPrice = p.price;
  }
  r.catCount = Object.keys(r.cats).length;
  r.avgPrice = Math.round(r.priceSum / r.total * 100) / 100;
  return r;
}
```

**两个最容易错的坑**：
- 极值初值写 `0` → 最便宜会变成 0。正确是 `±Infinity`。
- `while` 忘了 `idx++` → 死循环卡死。本作业推荐用 `for...of`，最省心。

**(b) 清空首页写死的统计**：把 `index.html` 里 `<section class="stats"> … </section>` 的内部数字删掉，只留空容器：

```html
<section class="stats" id="stats"></section>
```

**(c) 在 `</body>` 前加脚本**，引入数据并调用你在第二步写的 `aggregate`（把 aggregate 函数也放进这段脚本，或单独存 `aggregate.js` 一起引入）：

```html
<script src="products.js"></script>
<script>
function statBox(num, label) {
  return '<div class="stat"><div class="num">' + num + '</div><div class="label">' + label + '</div></div>';
}
const r = aggregate(products);
document.getElementById("stats").innerHTML =
  statBox(r.total, "商品种类") + statBox(r.stockSum, "库存总量") + statBox(r.catCount, "分类数");
</script>
```

**(d)** 浏览器打开 `index.html`，统计条就会显示真实数字。**改 `products.js` 里的数据，刷新即变**——你就第一次体验了「数据驱动」。
