AIGC 时代个人定位与能力树

原 UI 设计师 → 高职计算机系讲师 → AI 内容方向 ｜ 2026 年 9 月
先把问题切开。"创业、打工、还是当老师"——这是变现形态问题，问的是"钱从哪个管子流进来"。 而"我是谁、我要具备什么能力"——这是身份内核与能力结构问题。 这两件事必须分开回答，而且顺序不能反：内核决定你学什么、做什么作品、积累什么资产；形态只是装这些东西的容器。 内核空了，换一百个容器也没用。
图 1　三层问题：内核 → 能力 → 形态，只有前两层是"个人发展"

一、定位不是选出来的，是筛出来的

定位这件事最容易做成"列一堆方向让我挑"。换个做法：用三个筛子，把不可能的先筛掉，剩下的就是答案。

图 2　四层能力与被取代风险：越往上越"反 AI"，也越稀缺

筛子一：这件事 AI 能不能做

L1 正在被产品直接吸收——各平台开始内建一致性功能（角色参考、要素锁定、多图参考），"会打字、会复制粘贴"这一层已经不构成职业。L2 的问题是：AI 的产能越大，"产出"越不值钱。

而 L4 是唯一一层"AI 越进步、需求越大"的位置。原因很直白：一致性的问题就是 AI 制造出来的。AI 每一次生成都在引入随机性，产能越高，漂移、闪烁、跳脸越多，就越需要有人来定义"什么叫做对了"、并把它锁住。

筛子二：今年的活儿能不能变成明年的资产

  • 工具技能：不能。版本每 6–10 周动一次，今年的熟练度明年归零。
  • 单件成品：不能。一单一结，做完即止。
  • 规范与资产库：能。角色卡、风格锚点、三视图规格、验收清单——做一次，用无数次，而且越积越厚。

筛子三：这个位置她能不能守住

这是最关键的。2026 年 AI 短剧美术指导的真实招聘要求里，出现频率最高的几项是这样的：

岗位 JD 原文（2026 年 AI 短剧 / 漫剧美术指导，内地岗位）
"熟练掌握：提示词撰写、参考图控图、LoRA 训练 / 调用、种子锁定、局部重绘、图生图一致性控制"
"懂批量量产、资产复用逻辑"
"有解决 AI 角色一致性、画面闪烁、手部崩坏实战经验者优先"
"具备影视镜头语言认知，懂景别、光影叙事、电影感调色逻辑"

再看团队分工。一个 5–6 人的漫剧小组里，导演 / 美术总监只有 1 人，职责是"统筹创作、把控风格、审核质量"，岗位说明里直接写着一句关键判断："关键是审美判断，而非绘画技能"；而真正的量产执行由 2 名"抽卡师"承担。

把这两条放在一起看，结论很清楚：产业已经把"定义标准"和"执行量产"分成了两层，而且前者只需要 1 个人、后者需要一群人。她的 Design System 背景，恰好是前者的母语。

二、定位：AI 内容的视觉资产架构者

一句话定位：她不是做内容的人，是定义内容如何被生产的人。

用一句能对外说的话："我做 AI 内容的视觉标准——给团队定角色规范、建资产库、把住一致性的最后一道关。"

这个定位由三个动作构成，而这三个动作分别对应她身上三块现成的肌肉——这是它成立的根本原因：她不是在转行，是在把已有能力翻译成新领域的语言。

图 3　定位的三个动作，分别对应她已有的三块能力
为什么说这是"Design System 的直系迁移"
2026 年业界通行的角色一致性提示词结构，是这样的七段固定分层：
Identity（永不改） → Wardrobe（少改） → Scene（常改） → Camera → Light → Style → Negative（排除项）

"整段身份描述必须原样复制、永不重写；换场景只改后面几段。"——这句话，UI 设计师听着熟不熟？
这就是组件库的使用规范：基础属性锁定，只有状态与内容可变。行业里叫 character bible、turnaround sheet、version 命名规范；她叫过它组件规范、状态管理、命名约定。名字换了，方法论一个字没变。

三、能力树

技能清单最大的坑是"列一堆名词、没有优先级、也没有终点"。所以这棵树按半衰期分层：越往上越容易过期，越往下越值得投入。

ComfyUI 节点工作流缺中高 能看懂、能改、能把一套调好的工作流存成模板交给别人跑
视频模型选型缺中高 拿到一个镜头需求，能说出该用哪个模型、用哪种模式（图生视频 / 首尾帧 / 参考生视频 / 运镜控制）
枝 C 景别 / 机位 / 光位 / 轴线弱高 能看懂分镜表，能指出一个镜头表里的轴线错误
镜头衔接与连续性弱高 能把一段剧本拆成 30–40 个镜头，且镜头之间不跳、不闪
剪辑节奏与调色统一弱中 能独立完成一集成片的终审，指出调色不统一的镜头
枝 D 需求翻译与规格化有基础高 把甲方"要高级一点"翻译成一份可验收的书面规格
报价 / 合同 / 验收节点缺高 能独立谈下一单、签下来、收预付款、按节点交付
作品集与个人表达缺最高 有一套能在 3 分钟内讲清楚的 before / after 案例（崩脸 vs 不崩脸）
枝 B 的关键技术判断（这是她的技术底线，不用再往下钻）
一致性方案的实测指标：LoRA 微调 90–95%（需 15–30 张多角度高清图，一次性训练成本，适合长期连载的主角）；IP-Adapter / FaceID 75–85%（1–3 张参考图，即插即用，适合配角与快速出图）；Reference-Only + ControlNet 约 70%（单张源图，适合单次场景过渡）。

她需要掌握的是选型判断与数据规格，不是训练器背后的数学。字节开源的 HyperLoRA 这类"免逐角色训练"方案出现后，训练成本还会继续下降——这恰恰说明"训练"本身会越来越不值钱，而"定义训练什么"越来越值钱。

六、回到那个问题：打工、当老师、还是自己干

答案是：这不是三选一，而是"一个内核 + 三种容器"，并且三种容器的权重随时间变化。但具体到她的情况，三者的可行性差别很大，必须讲清楚。

图 7　三种形态对同一内核的兑现能力对比

为什么"打工"这条路要特别说明

数据摆在这里：2026 年内地 AI 短剧 / 漫剧美术指导岗位的实测薪资是 6–8K，硬门槛是"美术 / 影视 / 数字媒体专业 + 1–3 年短剧或 AI 美术资产经验 + 完整项目作品集"，且要求坐班。而真正给到高薪的（AIGC 影视方向负责人 50–80K 级别）要的是产业资历与团队管理能力。

也就是说：她现在的定位，在雇佣市场上被定价在 6–8K——不是因为定位错了，是因为"标准层"这类岗位在小城市的公司里被当成了执行岗来招。这正是为什么她必须以"自己干"的形态兑现：标准层的价值，只有在你拥有定价权的时候才收得到。

唯一的例外是"外聘顾问 / 特约美术指导"——按项目计费、不坐班。这本质上是"自己干"的变体，不是打工。

七、给你（张老师）的配合点

你负责什么

枝 B 的"能用"以上部分：ComfyUI 批处理与 API、素材命名与版本管理、初剪半自动、资产库的文件结构。这些是你 CourseOS / Yoo Code 能力的直接外溢。

边界：你做管线，她做规范。你决定"怎么批量跑"，她决定"跑出来的东西什么算合格"。

不要越界的地方

不要替她定义视觉标准。她一旦变成"你说怎么做我就怎么做"，她的内核就废了——那正是她唯一不可替代的东西。

判断标准：如果一件事她能独立对甲方说清楚理由，那就是她的；如果她只能说"张说这样好"，那就越界了。

一个必须现在就做的动作
上面所有安排的前提，是你们单位的对外兼职与取酬口径。有的院校允许横向课题、不允许个人持股；有的允许个人劳务、不允许占用工作时间。先问科研处 / 人事处，再动。别先干后问。这个问题不解决，后面所有的形态设计都是纸上的。

八、一句话总结

定位：AI 内容的视觉资产架构者——定义标准、验收质量、传递标准。这三件事分别对应她已有的 UI 规范能力、设计师判断力、以及教师身份。

能力树：根是视觉判断力与规范思维（不用学）；干是视觉资产架构（要立住）；四枝里 A 视觉规范工程是本行迁移、投入产出比最高，B 生成技术栈与 C 影像语言是必须补的短板，D 交付与商业是最缺的一块；叶是工具，只保持会用。

发展：0–6 个月跑通一条线并产出一套能复现的资产包；6–18 个月用 3–5 个外部真实项目把规范验证成可交付的文档；18–36 个月让标准脱离她本人运转。

形态：教师身份是底盘不是终点，打工短期不通，自己干是唯一能兑现标准层定价权的形态——但形态是容器，先把内核做实。
数据来源：工业和信息化部教育与考试中心 AIGC 应用工程师初 / 中 / 高三级能力标准；2026 年生成式 AI 人才四层能力模型；2026 年 AI 短剧 / 漫剧美术指导与美术负责人岗位招聘要求；AI 漫剧团队 5–6 人小组岗位分工分析；角色一致性技术方案实测指标（LoRA 90–95% / IP-Adapter 75–85% / Reference-Only 约 70%）；2026 年 AI 视频生成模型能力对比（Seedance 2.0 / Veo 3.1 / Kling 3.0 / Wan 2.6 / Hailuo 2.3）。
说明：薪资与模型参数均为 2026 年中的时点数据，AI 视频领域版本迭代周期约 6–10 周，工具层信息请以实际使用时为准。
