剩余 60 学时，一条主线贯穿到底；期末交出来的不是习题集，是一条能跑的电商商品上架图生产线

一、先把账重算：不是 74，是 60

课时口径变了，整个方案要跟着重排。教材配套大纲写的是 86 学时，但实际排课是 72——第 1、2 章用掉 12，剩下只有 60。而教材第 3 到第 11 章按大纲需要 74 学时。

这中间有 14 学时的硬缺口。它带来的结论和上一版不同：这 14 学时不可能靠"每章省一点"抠出来，每章省 1–2 学时总共也只有 8 学时，还把每章都讲成赶进度。必须整块动第 10、11 章。

取消第 11 章是最容易被质疑的一步，所以要先把理由说死。大纲给第 11 章写的课程目标是"实现一个飞机大战项目"，考察的是多文件组织、状态管理、事件循环。这些目标一条都不用放弃，换成"实现一个可交付的电商素材批量生产线"后达成度反而更高：飞机大战交付的是一份只能在自己电脑上跑的游戏，而后者交付的是一套真实上架图，能放进作品集、能在面试时打开链接，也能直接讲清楚"一张实拍图怎么变成一整套商品图"。

唯一的代价是"趣味性"。但趣味性在这个学期由训练营承担——它不是消失了，是换了个地方。

二、核心改法：从"换案例"升级为"一条主线"

上一版的做法是每章换一个案例：第 3 章讲生成任务状态，第 4 章讲提示词模板，第 5 章讲参数表。这比原教材好，但有个没解决的问题——案例之间不累积。学期末学生手里还是十几个互不相干的练习，拼不出一个东西。

这一版改法更彻底：整学期只做一个项目，一个脚本从开学长到期末。

项目定为一个文件：manhua.py。它的最终形态是——读一份商品照片与上架需求清单，自动去底白底、批量做场景化、质检筛选废片，输出一整套上架素材包与生产记录。

从第 3 章起，每章只做一件事：给这个脚本加一个构件。学 if 就是给它加状态判定，学文件就是给它加归档，学类就是给它加 Product（一个商品就是一类对象）。学期结束时，它不是十几个练习，是一个能跑的东西。

这样做最直接的好处是解决了你说的"太慢"：

  • 不用每章重建背景。传统讲法每换一个案例要花 5–8 分钟解释"这个程序是干嘛的"，一学期重复十次。一条主线只需要解释一次，第一次课做完，后面每章直接进入"这次加什么"。
  • 代码可复用。上一章写的函数下一章直接调用，学生不用每次从头写。实际教学时间能省下相当一部分。
  • 作业即项目进度。不存在"作业做完了但对期末项目没用"的情况，学生每一次作业的边际收益都看得见，这是专科生唯一有效的持续动力。
  • debug 有上下文。报错不再是孤立的练习错误，而是"我的脚本哪里坏了"——这是真实开发的心理状态，也是我们从 L1 推到 L3 必须经历的一步。

第 8 章是全案枢纽，建议全知识点保留。大纲要求的类、属性、构造、封装、继承、重写、多态，七个知识点可以全部落在 Product 一个类上：

属性 = 参考图路径、材质、固定种子｜方法 = 一致性打分｜封装 = 参数不外泄、只能通过方法改｜继承 = Product 派生 Character（漫剧角色，预留的第二条线伏笔）｜重写 = 不同商品/角色的检查规则不同｜多态 = 统一调用 score() 而不用关心类型。

学生学 OOP 普遍卡在"为什么要写类"。而"一个商品就是一类对象，每个对象带着自己的参考图和参数"，既是标准 OOP，又正好是一致性工程的核心心智模型。这一章教好了，后面三个模块才有落点。

五、四个赛道模块：只在课内做"能跑通"的最小版

原则先说清楚：课内只负责让每个学生都跑通一次，深度一律交给训练营。60 学时里只有 16 学时给赛道内容，任何"讲透"的企图都会把课讲崩。

模块 A　调接口与密钥　4 学时

  • HTTP 与请求响应（1）——不讲协议细节，讲"发一个请求、拿一段 JSON"
  • requests 与 JSON 解析（1.5）
  • API Key 与环境变量（1）——不要把密钥写进代码，这是职业习惯的起点
  • 限流与计费（0.5）——让学生第一次意识到"每次调用都占额度"
  • 当堂交付：真实出图第一张。这一刻是全学期的情绪高点，前面的铺垫都在这儿兑现——用老师给的 key，把一张实拍图跑成白底图 + 场景图

模块 B　批量生产与一致性　6 学时

  • 任务编排与节流（2）——队列、并发上限、失败重排
  • 参考图锁定与种子（2）——整个赛道的技术核心：怎么让同一件商品在不同场景里外观一致（不是"第 1 集和第 50 集是同一个人"，而是"第 1 张和第 50 张是同一个杯"）
  • 候选打分与废片筛选（2）——用规则而非肉眼：白底纯度、构图比、清晰度、文字占比
  • 当堂交付：一次跑 100 张，自动筛出候选。这一步做完，学生直观理解"产能"两个字

模块 C　出片与交付　3 学时

  • 按 SKU 分目录归档（1）——每个商品一个文件夹，含白底图、场景图、JSON 元数据
  • README 与生产记录（1.5）——生产记录是这一模块的重点：工作流版本号、废片率、单 SKU 耗时、成本核算
  • 合规标注（0.5）——AI 生成的图上架须标注「AI 合成」（市场监管要求），这是红线教育，不是可有可无
  • 当堂交付：一套商品上架素材包（白底 + 场景图 + 生产记录）。这套素材包就是训练营招募时给学生看的东西

模块 D　期末项目周　3 学时

完整跑通一批商品上架图 + 小组答辩。答辩只问三个问题：你的脚本哪里最容易坏？坏了怎么知道？废片率多少？——这三个问题答得上来，就说明真的理解了工程是什么。

七、为什么这样能更快：四个机制

"太慢"不是讲得慢，是大量学时花在了不产生积累的地方。这套方案用四个机制把它压回来：

机制具体做法省在哪
一条主线整学期一个 manhua.py，每章加一个构件省掉每章 5–8 分钟的背景解释，一学期约 2 学时；更重要的是让作业产生复利
讲练一体自带笔记本课堂，两节连排按「讲 20 分钟 + 做 25 分钟 + 收尾 5 分钟」切不留"回去练"。专科生的课外完成率极低，课上做完等于把有效学时翻倍
先给成品再拆第 1 周先亮青瓷茶漏真实出图闭环图，之后每章先演示"加完这个构件会变成什么样"省掉"学这个有什么用"的反复解释与相应的注意力损耗
砍掉不产生构件的铺垫turtle、Pygame、递归、飞机大战、异常体系全讲直接腾出 14+ 学时，这是缺口的主要来源

第 2 条（讲练一体）的前提现在已具备：学生自带笔记本进课堂，理论课和动手在同一空间完成。新增的 16 学时赛道内容全部可以课上做，不留课后作业——这是专科完成率的最大保障，也意味着教考分离与否都不会卡住"动手"这一环。

八、课内与训练营怎么分工

你说"讲到一半同步开也行"——这个判断是对的，而且越早越好。原因不是课时，是心理：等到课内讲完接口再开训练营，学生对 Python 的认知早就定型成"做习题"了。

课内（60 学时 · 全员）训练营（社团 · 自愿）
定位保底：让每个人都跑通一次加速：让愿意的人做出能投的作品
内容语法 + 一条最小电商素材管线审美判断、平台规则、真实项目、接单
深度跑通即可，不追求好看追求"能投稿""能被商家接受"
评价构件是否交付素材包是否有观众、是否有甲方认可
启动已在进行中第 4 周启动

九、考试怎么办

大纲写明期末闭卷百分制（平时 30% + 期末 70%）。这反而是这套方案最稳的地方：换的是载体，不是知识点。学生考的是 f-string、推导式、try-except，跟他用这些做了飞机大战还是电商素材包，完全没有关系。

范围处理
必考不变分支循环、字符串方法与格式化、列表字典推导式、函数参数与返回值、文件读写、类与对象、try-except
不再考turtle 绘图、Pygame、递归、jieba/wordcloud、飞机大战相关
新增不进笔试模块 A/B/C 的赛道内容不进闭卷，全部计入平时分

需要你确认一个风险：这门课是不是教考分离。如果期末由教研室统一命题或抽考，取消第 10、11 章就有出题风险。如果是任课教师自主命题（大多数高职基础课如此），则完全可控。这一点确认后，取消清单才能最终定稿。

平时分的挂法要改。原结构里"上机 20%"是最合适的挂钩点：把构件 1 到构件 10 的交付情况折算进上机成绩，其余（出勤 5、作业 5）不变。赛道内容如果不计分，学生不会重视——这是把 16 学时投入打水漂最常见的原因。

十、现在要做的三件事

  1. 确认一件硬事：期末是否教考分离。（场地问题已因"自带笔记本课堂"而消解，讲练一体无需额外资源。）如果是任课教师自主命题，第 10、11 章的取消清单就能最终定稿；若由教研室统命题，则需保留可考知识点清单。
  2. 准备第 1 周的青瓷茶漏真实出图样例。用你拍的青瓷茶漏跑通的产物（白底图 + 4 张场景图），能当场说清"这是一张实拍图，经脚本变成一整套上架图"。这一件事的投入产出比高于后面任何一章——学生第一眼看到的是"我能做出真东西"，而不是"又要学语法"。
  3. 训练营的算力本周定下来。第 4 周启动，第一周不装环境但要出图，算力是唯一可能让它开不起来的硬条件。好消息是 S1 去底（UAPI）与 S2 场景化（Seedream 4.0）当前均为免费额度，学生各自注册、各用各的，教师 key 仅作演示——这条线成本已清零。

最后一个提醒：一年窗口里，别追求体系完整，追求"能拿出的东西"。学生去实习面试，掏出来的是一个作品链接，不是成绩单。这份方案里所有不能落到可见产出的环节都已经砍掉了，剩下 60 学时每一格都对应一个能跑的构件——这是它能在一个学期内做完的唯一原因。

还有一件事别忘：训练营天然就是你的实验班，而且比强制分班干净——自愿报名意味着选择偏差可以正面处理，未报名的同专业学生就是现成对照组。基线数据必须在第一周采集（课前问卷 + 一次小测），事后补就废了。
