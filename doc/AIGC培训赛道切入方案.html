一、赛道上其实有五个角色

培训机构这条链上，钱和风险不是均匀分布的。同样是"做 AIGC 培训"，站的位置不同，投入和结局完全不一样。

角色要干什么投入收入方式建议
场地/资质方办学许可证、校舍、宿舍、全职教务重资产，百万级学费大头不碰
招生方流量投放、销售团队、渠道、私域获客成本极高，最卷佣金 / 差价不碰
课程方课程研发、课件、实操素材、迭代一次性投入，主要是时间授权金 + 分成 / 买断 / 研发外包主攻
讲师方交付授课时间课酬，按天或按课时结算起步
认证方发证、背书机构资质溢价分成后期绑定
为什么这样选：你们缺的恰恰是赛道里最难的两件事——招生渠道和办学资质。而你们有的，是别人最缺的：真实产业经验（双师）+ 能交付的高质量课程内容。用自己有的换别人有的，而不是拿短板去硬拼。

二、为什么不能自己做 C 端就业班

这条路的钱看得见，但坑在下面。四个硬理由：

四条不能碰的理由

  • 重资产、重运营。办学许可证、固定场地、全职师资、宿舍、就业服务团队，一样都不能少。两位在职教师做不了，也不该做。
  • 依赖就业承诺，而承诺极易翻车。市场对 AI 岗位的真实情况是"复合型人才百万级缺口"与"初级执行岗过剩"并存。承诺就业的学员大多达不到复合型门槛，兑现不了就是纠纷。
  • 口碑正在清算。2025 年第四季度消协统计，AIGC 技能培训投诉量同比增长 65%，集中在虚假宣传、退费困难、就业承诺无法兑现三项。现在进场做 C 端，等于接盘。
  • 你们没有销售团队。这是整条赛道最难的一环，也是最烧钱的一环。

三、位置一：讲师方（起步，先拿案例）

这是零投入、最快见到钱的入口，而且目的不是赚钱，是攒案例、攒背书、攒渠道。

三类客户，按优先级

  • 本地职业院校的师资培训（首选）。全国设计、数媒类专业教师正被批量要求转型 AIGC，供给严重不足。她的身份天然合适——自己就是转型过来的设计师，又是老师，讲的是"我怎么把这门课上起来"。院校方有预算、有经费渠道、结算规范。
  • 本地中小企业的市场部 / 电商部。他们要的是"出图更快、详情页更便宜"，不是技术。半天到一天，决策快。
  • 本地短剧 / 电商代运营公司。最懂钱在哪，也最可能成为后续课程采购方。

卖点必须钉死一句话

不是"教你用 AI 工具"，而是"教你怎么让 AI 产出的东西能商用，而且一百个镜头不崩"。市面上 AIGC 课程绝大多数停留在基础工具操作层面，师资由兼职讲师或应届毕业生组成——这是行业公开承认的问题，也正是你们的机会。

四、位置二：课程方（这才是真正赚钱的位置）

讲师方是一份时间换一份钱。课程方是一次开发、多次收费。三种变现模式：

模式怎么操作收入适合阶段
课程研发外包按项目制为机构开发课件、脚本、讲义、题库、实操素材，一次性或分阶段结算项目款，按套计价阶段 1–2，最快
授权 / 白标把课程授权给机构或平台使用，对方可用自己的品牌销售授权金 + 按销量阶梯分成阶段 2，主力
版权买断一次性买断课程版权保底费用 + 分成奖励阶段 3，按需
关键点：授权和研发外包在用工性质上属于项目合作 / 承揽，不是雇佣关系——这对在职身份至关重要（详见第七节）。而"课程方"不需要办学许可证、不需要场地、不需要招生团队。

五、四阶段路线

阶段 0

合规确认

第 1–2 周

  • 问清单位对外兼职取酬口径
  • 确认能否走横向课题 / 技术服务合同
  • 确认能否持股或合作办学
  • 明确 IP 与课程版权归属规则
阶段 1

讲师方

第 1–3 月

  • 接院校师资培训、机构外聘课
  • 起步价 8,000–15,000 元/天
  • 第一单可降价，条件是换授权案例
  • 目标不是钱，是案例与背书
阶段 2

课程方

第 3–9 月

  • 把课标准化成课程包
  • 含大纲、课件、素材、考核、讲师手册
  • 授权 / 白标 / 研发外包三条并行
  • 一次开发，多次收费
阶段 3

垂直与生态

第 9–18 月

  • 绑定行业认证，抬高客单价
  • 开面向从业者的高阶短训
  • 走技术服务合同，不做就业承诺
  • 考虑毕业生实习输送的闭环
阶段 3 的方向选择：不要做"零基础转行就业班"（红海 + 投诉重灾区），要做面向已经会用工具、但做不出能交货的东西的人——一致性控制、批量生产管线这类高阶内容。2–3 天，客单价 3,000–8,000 元，不需要就业承诺，不需要办学许可，投诉风险极低。

七、合规：能做与绝对不做

可以做（用工性质清晰、风险低）

  • 特约外聘讲师。单次公开课、短期集训营、周末专题课，只按授课课时结算酬劳，不接受日常人事管理，课程结束本次合作即终止。
  • 课程研发与课件外包制作。题库编写、课程脚本、配套讲义、课程视频剪辑等项目制外包，独立交付，一次性或分阶段结算。
  • 知识付费专栏 / 单节课程合作。与线上平台合作，按播放或售卖分成结算。
  • 院校师资培训与横向课题。走学校账，合规且计入双师业绩，是最省心的起步通道。

绝对不做

  • 不办全日制培训班、不招脱产学员。无办学资质的培训业务，任何结算方式都兜不住风险。
  • 不做就业承诺与保薪承诺。这是投诉量增长 65% 的主要来源，也是最容易翻车的一项。
  • 不碰培训贷、分期诱导。违规手段，一旦涉及就是经营风险而非民事纠纷。
  • 不接受固定排班考勤的"专职授课"安排。长期固定课时、接受统一考勤与绩效考核、按月发固定薪资，实践中极易被认定为事实劳动关系。
  • 不长期独家绑定单一机构。同一人连续十余月稳定为单一机构全职式服务，税务与人社部门会重点核查用工实质。
第一条待办：上面所有判断的前提，是你们单位的对外兼职取酬口径。有些院校允许横向课题、不允许个人持股；有些允许个人劳务、不允许占用工作时间。先问科研处和人事处，再动。别先干后问。

八、90 天动作清单

  • 向科研处 / 人事处确认：横向课题路径、个人劳务路径、持股与合作办学边界。
  • 确立一个对外统一名号与一句话定位，用于所有对外材料。
  • 搭一套可演示的角色一致性工作流——这既是课程原型，也是后续产品原型。
  • 产出三份对外物料：课程大纲一页纸、三种报价模板、一段 3 分钟的 before / after 演示视频。
  • 列出本地 20 家目标客户（院校 10 家、企业 10 家），逐个触达。
  • 拿下第一单，可以是免费或半价，唯一条件是换取可授权的案例与推荐。
  • 把第一单的完整交付过程文档化，直接转成可授权的课程包初版。
  • 90 天末复盘：若询盘可稳定产生，再决定是否投入课程包标准化。
