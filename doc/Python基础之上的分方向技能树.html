Python 课程扩展设计 · 技能树

Python 基础之上，各方向还要补什么

以现有「Python 基本开发入门」为起点，按五个就业方向 × 能力级别反推知识缺口与技能补充清单

依据：53 条真实招聘 JD（含 AIGC 补录 7 条）+ 4 份行业报告 ｜ 起点：Python 基本开发入门 ｜ 用途：课程模块设计与课时分配

一、先定位：现在的课覆盖到哪一层

在回答"还要补什么"之前，得先说清楚"已经有了什么"。

一门 Python 基本开发入门通常覆盖的是：语法与数据类型、流程控制、函数、文件读写、异常处理、基础面向对象、少量标准库。这些内容对标到能力分级，大致落在 L1（能读懂、能改参数），学得好的学生可以到 L2。

能做的事是明确的：把一段业务需求翻译成代码逻辑、读懂别人写的脚本、在 AI 辅助下改出一个能跑的小工具。

但 JD 里反复出现的那些要求，它还没覆盖。我把这些缺口归成五条——注意，这五条不分方向，是所有岗位的共同缺口：

  1. 与外界通信：HTTP 请求、调 API、JSON 解析、密钥管理。JD 原文里"API 封装对接""能直接调 API 上手更快"指的就是这个。
  2. 处理真实数据：SQL 取数、Pandas 清洗。学校里的数据通常是干净的，真实数据不是。
  3. 让模型干活：Prompt 设计、调用大模型接口。这是近两年新增的一层，课本里几乎没有。
  4. 工程协作：Git、虚拟环境、依赖清单、日志。学生交作业用压缩包，企业不这么干。
  5. 交付成别人能用的东西：参数化脚本、接口、定时任务、简单界面。作业是"跑一次给老师看"，工作是"跑一百次给同事用"。

一句话概括这个缺口：不是基础没学好，是基础之上缺一层"连接器"。

现有课程教的是用 Python 表达逻辑；企业要的是用 Python 接上外部世界——接数据、接模型、接人。这层连接器就是技能树的共用主干，不分方向都得补；补完之后，才轮到各方向的分叉。

二、技能树总览

三、共用主干：不分方向都要补的 5 项

这一层的判断标准是：它出现在所有方向的 JD 里，或者它是所有方向的隐性前提。课时估的是"讲 + 练"的最小量。

项目具体补什么建议课时为什么是它
1. 命令行与运行环境 venv 虚拟环境、pip 装包与镜像源、requirements.txt、路径与中文编码、Windows 下最常见的几个报错 2 实习生第一周卡住的地方，往往不是代码，是环境。这一项不补，后面每节课都要花十分钟救场
2. Git 与 GitHub clone / add / commit / branch / PR、写一份能看的 README、把自己的项目发布成公开仓库 2 它是作品集的载体。学生毕业后能带走的不是作业压缩包，是一个链接；面试时被问"有没有作品"，指的也是这个
3. HTTP 与调 API 请求与响应、状态码、JSON 解析、requests、API Key 与 .env、超时重试与错误处理、看官方文档调通一个陌生接口 4 最关键的一环。JD 原文里"API 封装对接""能直接调 API 上手更快""了解 API 接口调用等概念"全都落在这里。补了它，学生才第一次让 Python 连上外部世界
4. 读文档与读报错 Traceback 从下往上读、最小可复现、官方文档的结构（Quickstart / Reference / Cookbook）、怎么提问才有人答 贯穿 决定学生离开课堂后还能不能继续学。框架两年一换，这项能力不换
5. 与 AI 协作写码 把需求说清楚、给足上下文、让 AI 解释报错而不是直接改、验收 AI 生成的代码（跑通、看懂、能改） 2 Vibe Coding 已经写进校招 JD：Inspire（原 Thoughtworks）AI 产品经理岗位职责中明确列出该模块；另一条 JD 写的是"能在大模型辅助下完成简单代码的编写、修改与调试"

四、五个方向各自的技能树

下面每个方向给三样东西：要补的知识、用到的工具、做到什么算达标。最后一项最重要——它是评价标准，也决定了学生能不能拿出作品。

方向 ①AI 数据与训练 · 目标 L0–L3

Python 在这里的角色：把数据说清楚。这是需求基数最大、门槛最低、也是最多学生的第一份工作。它的重要性不在于薪资上限，而在于它是通往其他方向的台阶——先进入这个行业，再横向移动。

级别要补的知识工具做到什么算达标
L1 会用标注工具、理解标注规范与一致性、能跑通别人写好的脚本并改参数 标注平台、Excel 按规范完成一批标注并通过质检
L2 SQL 取数（SELECT / WHERE / JOIN / GROUP BY）、CSV 与 Excel 读写、Prompt 基础 SQL、Pandas 入门 给一张表，能自己取出要的数
L3 Pandas 清洗（缺失 / 重复 / 类型转换 / groupby / merge）、基础统计、可视化、数据质检与一致性判断、Prompt 工程与效果评测 Pandas、NumPy、matplotlib 或 pyecharts 独立完成取数 → 清洗 → 分析 → 出图 → 说结论全链路；或产出一份标注规范 + 质检报告

JD 依据：上海坤载元码（郑州）AI 训练师，大专，5-10K×13：「熟练掌握 Python，能使用 Pandas、NumPy；精通 Prompt 工程」；四川中鸿数智（遂宁），专科，4.5-5.5K：「掌握 C/C#/Java/JavaScript/Python/Node.js 等任意一种编程语言」——注意后一条，它考的是"会编程"而不是"精通 Python"。

建议课时：10–14。其中 SQL 4、Pandas 6、可视化与质检 2–4。

方向 ②AI 应用落地（含 AIGC 支线）· 目标 L3–L4

Python 在这里的角色：把模型接进业务。薪资上限最高，也最吃作品——族内 JD 几乎都写"有可展示的项目成果"。这一支是课程里最值得投入的方向，但要承认：能走到 L4 的是少数学生，教学上应按"选修 + 实训"设计。

级别要补的知识工具做到什么算达标
L3 调通大模型 API（messages 结构、temperature、token 与成本意识）、结构化输出（JSON mode）、Prompt 工程（角色 / 示例 / 约束 / 输出格式）、批量调用与失败重试 OpenAI 兼容 SDK、requests 做出一个结果可稳定复现的问答或生成脚本
L4 RAG 全链路（文档解析 → 切分 → embedding → 向量库 → 召回 → 重排）、Agent 与 Function Calling、MCP 概念、FastAPI 封装、asyncio 并发、效果评估与日志 LangChain / LlamaIndex，或先用 Dify / Coze 低代码入门；FAISS / Milvus；FastAPI 交付一个可演示的知识库问答或 Agent，并且能说清"比不用 RAG 好在哪"——说不清就是没做

支线 · AIGC 内容生成（4–6 课时小模块）

这一支的特点是：Python 的用法不同，但层级相同。数据方向是"取数 → 清洗 → 出图 → 结论"，Python 服务于判断；AIGC 是"调接口批量生成 → 脚本串工作流 → 批量筛选质检"，Python 服务于产能。要补的只有四项：生成类接口调用、批量生成与文件处理（PIL、ffmpeg 命令行）、ComfyUI 或 SD 工作流的理解、批量筛选去重与质检。

它的额外价值在于产出物可见——图、视频、漫剧本身就是作品集素材，比一份数据分析报告更容易让学生拿得出手。两条边界要守住：不要上成某个具体工具的操作培训（工具两年一换，教"调接口 + 串流程"才不贬值）；向学生推荐 AIGC 岗位前必须先做招转培筛查。

JD 依据：武汉「大模型 AI 应用开发工程师」，大专应届，1-2万：「Python + LangChain / AutoGen / Milvus / FAISS；RAG 搭建、Agent 开发、模型编排」；海妖科技（成都）AI Agent 研发：「扎实 Python 基础、FastAPI、asyncio；Prompt 调试；RAG 清洗切片」；四川晟昇文化（成都）AIGC 应用工程师，大专 1 年以下，7千-1.4万：「熟练使用 Python 进行脚本开发与流程自动化」；内蒙古数智云（包头）7-12K，大专：「熟悉 Python 是加分项，能直接调 API 上手更快」。

建议课时：方向主干 16–20（选修/实训）+ AIGC 小模块 4–6。建议先上低代码平台（Dify / Coze）让学生两天内看到完整效果，再回头讲 LangChain，否则抽象的链路概念很难落地。

方向 ③AI 产品与运营 · 目标 L1–L3

Python 在这里的角色：能自己验证想法。这一族对 Python 深度的要求最低，但对"能不能动手验证"的要求最高。它的信号非常明确——阿里巴巴那条 JD 写的是「熟练使用 SQL/Python 分析用户行为数据，或具备基础技术开发能力」，这个"或"意味着两条路任选其一，不必都要强。

级别要补的知识工具做到什么算达标
L1 基础编程概念（看懂技术方案、能与工程师对话）、AI 工具的基本使用 — 听得懂技术评审，能写出不含糊的需求
L2 SQL 取数、Excel / BI 看板、指标常识（漏斗、留存、转化）、A/B 测试的基本概念 SQL、Metabase / 帆软 / Quick BI 自己拉一次活动数据，说出结论
L3 Prompt 设计与效果评测、Vibe Coding（用 AI 工具快速做出能点的原型）、把数据讲成决策建议 Cursor / 通义灵码 / 低代码平台、PPT 拿一个自己做出来的原型 + 一份数据分析结论去面试

JD 依据：Inspire（原 Thoughtworks）AI 产品经理：「具备扎实的编程基础与动手验证能力：能写脚本处理数据、能用代码快速验证想法」，岗位职责中明确列出 Vibe Coding 模块；杭州滨江（校招）8千-1.2万×14：「具备基本的编程（如 Python、Java 等）和数据分析能力」。

建议课时：6–8。可与"面向非技术岗的 Python 素养课"合并——47% 的春招岗位提出了 AI 要求，其中包含大量运营、设计、客服、行政岗，这本来就是一个被忽视的增量市场。

方向 ④AI 赋能与培训 · 目标 L1–L3

Python 在这里的角色：现场演示"AI 能干什么"。这是最被低估的方向，也是师范、教育背景学生的差异化赛道。它的 Python 要求不高，但有一条硬标准——必须能现场跑通一个小脚本，这是"讲得好"和"真懂"的分界线。

级别要补的知识工具做到什么算达标
L1 AI 工具全景认知（对话、画图、视频、办公）、Prompt 基础 主流工具 独立完成一个业务场景的 AI 改造小案例
L2 行业场景案例库（客服、电商、制造、教育、行政）、Prompt 工程体系化、讲清边界（不神秘化也不夸大） 案例库 讲明白一个场景为什么这样用、坑在哪
L3 课程设计与交付（大纲、实操手册、练习题、评估表）、表达与控场、企业内训流程（需求调研 → 方案 → 交付 → 评估） 课件、录屏 交付一节 45 分钟、带实操、可复用的课 + 录屏

建议课时：8–10（含教学法）。可与教育类专业的教学法课程打通，边际成本很低。

方向 ⑤传统 Python 开发 · 目标 L4–L5

判断：不作为主要就业锚点，但它是方向 ② 的能力底座。这一族需求增速 +19.3%，是全场最低；但反过来看，方向 ②里"FastAPI 封装、asyncio 并发"这些要求，本质上就来自这一族。

要补的：数据结构与算法基础、OOP 与常用设计模式、Web 框架（FastAPI / Flask / Django 选一）、MySQL 与 Redis、Linux 与 Docker 基础、单元测试、异步与并发、代码规范与日志。

建议：不在主干课铺开，以选修或实训形式向少数学生开放。它适合那批"真的喜欢写代码、愿意啃底层"的学生——这批人做其他方向也最有底气。

五、方向 × 技能域对照矩阵

六、如果只能加 16 课时，加什么

现实约束总是存在的，所以给一个最小可行路径。判断依据是：这四块直接把学生从 L1 推到 L3，而 L3 是专科可投岗位里样本最多、薪资跨度最大的一档。往上加 RAG 与 Agent 属于方向 ② 的专精，更适合少数学生选修。

顺序模块课时为什么是它
1HTTP 与调 API4唯一能同时服务五个方向的一项。补了它，学生第一次让 Python 连上外部世界，也才可能在后面调用任何模型
2SQL 取数4Python + SQL 是 JD 里出现频率最高的一对组合，近六成并列出现。而且 SQL 是唯一一门"学两周就能用一辈子"的技能
3Pandas 数据处理6把"能取数"变成"能出结论"。这一块直接对应 L3，也是数据方向薪资从 3 千跳到 1 万的分界线
4Git 与作品发布2前面三项做出来的东西，得有个地方放、有个链接能发给面试官

这 16 课时结束时，学生应该能交出这样一份东西：一个 GitHub 仓库，里面有一个脚本——它从一个公开 API 取数、存进本地、用 Pandas 清洗、输出一张图和一个结论，README 写清楚怎么跑。这份东西足够投 L3 那一档的岗位了。

七、明确不补的清单

同样重要的是知道不补什么。技能树最容易犯的错误是无限扩张，最后什么都教一点、什么都教不深。

  • 不补算法与数据结构全套——除非走方向 ⑤。JD 里几乎没有对大专岗的算法要求。
  • 不补模型训练（PyTorch 训练、微调原理）——JD 里出现"模型微调"的岗位基本都在本科起；大专可投岗位的原话是"了解大模型微调、RAG 搭建"，是了解，不是会做。
  • 不补某个具体 AIGC 工具的操作——ComfyUI、Midjourney 两年一换，教"调接口 + 串流程"才不贬值。
  • 不补前端——除非做方向 ② 的接口展示，能跑通即可，不必系统学。
  • 不补更多语法细节——语法从来不是瓶颈，"接得上"才是。把课时花在连接器上，收益率高得多。

八、教学落地建议

模块课时开设形式结课评价方式
共用主干（5 项）10并入现有课程独立跑通一个调 API 的小脚本，并提交到 Git
数据能力模块12并入或选修一份完整分析报告：取数 → 清洗 → 图表 → 三句话结论
大模型应用模块18选修 / 实训一个可演示的 RAG 应用，能说清比不用 RAG 好在哪
AIGC 自动化小模块6短模块一个批量生成 + 自动筛选质检的脚本，外加作品集
培训与表达模块8选修（师范类）一节 45 分钟可复用的课 + 录屏
素养课（非技术岗）8公共课一个用 AI 做出的原型 + 一份数据结论

最后回到一句话：现有课程教的是"用 Python 表达逻辑"，技能树要补的是"用 Python 接上外部世界"——接数据、接模型、接人。

前两件事靠共用主干（HTTP/API、SQL、Pandas），第三件事靠方向分叉（Prompt、RAG、课程设计、表达）。这个结构不会随着框架换代失效，因为换的是工具，不是"接"这件事。
