01先回答你最可能问的那句：机会在哪？

有，但不在你以为的那个地方。三件事，先说结论，后面再一条条给证据。

写代码这件事，变便宜了
不是说它不重要，是说它不再决定你被不被录用

AI 已经能把大部分常规代码写出来。于是"能从零写页面"不再是稀缺能力，靠这一条找工作的人变多了，价格就被压下来了。

但门槛并没有消失——它挪到了别的地方。

让 AI 在别人公司里跑起来，变贵了
这是本报告全部结论的核心

工厂、贸易公司、五金厂买了 AI 工具，但没人会装、没人会接数据、没人教员工用。这一批岗位就是为这件事开的。

它们不问你哪个学校毕业，问你"能不能动手做、能不能讲明白"。

所以你要练的，是后一半
好消息：这部分大家起点都差不多

读得懂别人的代码、调得通一个接口、能让不懂技术的同事学会用。这些学校很少教，本科课堂也不教，但对你们来说练半年就有差别。

图：AI 项目的五个环节。越靠前的两层学历门槛越高，越靠后的两层越看"能不能干活"。

这张图你要记住的一点

前面两层的岗位要求只会越来越严，那是研究生和大厂的事。而每当一家 AI 平台把产品卖给一家普通公司，就必须有一批人去把它装上、接通、教会对方员工——新增的岗位大量诞生在这里，并且这些岗位几乎不做学历筛选。

路一 · AI 交付实施（也叫 FDE）

简单说：AI 平台把产品卖给了某家公司，你负责去把它装上、接通、教给对方员工。这是三条路里技能含量最高、天花板最高的一条，也是唯一在招聘原文里明确提到 JavaScript 的一条。

这条路的涨薪秘密

这条路上，起薪 3 千和月薪 2 万的人，技术栈其实差不太多。拉开差距的是另外三件事：要不要直接面对客户、要不要对项目结果负责、以及会不会装环境和排错。

第三点值得你留意——往上走要的是横向的宽度（Linux 基本命令、部署服务、查日志、定位网络问题、对接数据库），不是纵向的深度（某个框架玩得多熟练）。这种东西练得出来。

路二 · 智能体与工作流搭建

简单说：用 Coze、Dify、飞书这类的拖拽式工具，把一家公司的某件重复工作变成自动流程。这条路最适合还在校的同学，因为它的门槛表达式非常友好。

为什么这条最贴在校生

因为它在招聘原文里直说了：课程作业也算经验。

招人的不是互联网公司，是肉制品厂、五金厂、原料加工厂、日化工厂。

这些公司从来没打算去跟大厂抢人，所以它们也不会按"985 / 211 / 名校"来筛简历。它们关心的是：你能不能来了就干活，能不能教会同事，能不能扎根下来。

说白了：学历歧视发生在人挤人的地方。这些岗位现在人不够，所以它们看别的。

同一批岗位里也有这一类：郑州两条校招岗位，4–6 千，一次招 150 人 / 15 人，工作内容是单纯的数据标注和清洗。

它们能进、门槛低，但不建议你把它们当成目标。判据很简单：一次招上百人 + 只要求重复劳动 + 薪资压在低位，说明企业把你当成可替换的人力，不是在开始培养一个岗位。临时落脚可以，别停在这里。

关于 JavaScript 的实话

在这些岗位上，JS 是入场券，不是定价权。

它出现的样子是"熟悉 Python 或 JS 脚本，能独立调试 API"、"能够阅读和修改简单代码"、"具备基础编程认知"——不是"精通 Vue 全家桶"那一档的强度，是"读得懂、改得动、接得上"那一档。

所以：不学 JS 不行，因为连招聘要求都看不懂；只学 JS 也不够，因为它不决定你拿多少钱。决定工资的是搭工作流、维护知识库、把事情讲明白这几样。

06从今天起到毕业，就这四件事

不需要额外报班，也不需要等多开课。下面四步都能在你现有的课程里做。

图：四步行动路线。每一步对应的是招聘原文里的具体要求，不是建议者的想象。

最省力的一步，其实是第三步

它不需要你新学任何技术。只要把现有每个项目的交付方式改一下：除了交代码，再交一份给别人看的操作手册、一段演示录屏、一次面向非技术同学的讲解。

成本是每个项目多花两三个小时，回报是：招聘要求里六次出现的那件事，你已经有实物可以拿出手。

07几句实话

这份地图上如果有坑，应该先告诉你。

关于起薪

你的第一份工作很可能只有 3 到 6 千。不粉饰这一点。

但你要看的是台阶而不是起薪：上面那张台阶图里，最低一档到最高一档中间有七级，而每一级往上要的东西都是具体、明确、能练出来的。对比另一条路——要求精通框架的那些岗位，它的难点在于门槛本身就是一堵墙，你得先在墙外站很久。

第一份工作的价值，在于让你站到了 AI 这条正在变宽的链条上，而不是站在正在被 AI 挤压的那条上。

关于"是不是就不用学难的东西了"

不是。这些岗位降低了深度要求，没有降低全部要求。天花板依然是技术性的：

  • 宁波 AI 产品交付工程师开到 1.58–2.17 万，要求 Linux、Java 运行环境、数据库和中间件部署、看日志排错
  • 珠海 AI 数字化专员上限 2 万，要求 ERP / HR 系统运维与数据对接、SQL 或 Python
  • 广州那条交付岗要求"有技术底子（脚本编写、SQL、API 对接），能独立完成 Demo 搭建和轻度开发"

规律是：入门靠"浅但有手感"，往上走靠"宽而不深"。要求你"更深"的台阶，爬起来很吃力；要求你"更宽"的台阶，练一练就上得去。

关于工具的保质期

Coze、Dify、各种新平台——这些名字在招聘里撑不过一年半。不要把自己的价值押在"我熟悉某个平台的按钮在哪"。

要押在不会变的那部分：HTTP 和 API 是怎么回事、数据格式怎么转换、流程怎么拆成步骤、看懂别人代码的套路、把事情写清楚讲明白。工具换了，这些还在。

关于这份数据的局限

  • 样本是全国范围的公开招聘，没有专门抓本省本市。你所在城市有没有这些岗位、有几家，还需要单独查一次
  • 岗位是某个时间点抓到的，会下线、会被填满，薪资也会变
  • 网络上的"AI 岗位平均月薪两万八""缺口五百万"这类说法一份都没采用——它们大多来自培训机构的招生文案，和真实招聘对不上。本页每个数字后面都有城市、公司和原文

08你大概还会问

按同学们最常问的顺序排的。

问是不是就不用学框架了？那 Vue、React 还学吗？

答　学，但目标要改。学到一个能把活干完的程度就够了，不必追求把所有高级用法都背下来。

理由是招聘原文：这批 18 条岗位里，没有一条写"精通某个框架"，但有四条写"能读能改简单代码""熟悉脚本"。时间是有限的，把它花在更能决定录用的地方。

问那 JavaScript 课还有必要好好上吗？

答　非常有必要，而且它是硬门槛。

打个比方：JS 在这些岗位里像驾驶证。没有它你连门都进不去——接口文档看不懂，报错看不明白，别人给的代码不知道从哪改起。但光有驾驶证也不代表工资高，真正拉开收入的是你能不能用它跑出活来。

问我不太爱说话，这些岗位是不是不适合我？

答　要分清两件事："外向"和"能把话说清楚"是两回事。

招聘要的是后者。它的原话是"能把复杂的 AI 逻辑翻译成老板听得懂的生意经"、"输出标准化操作手册"、"能展示作品"——没有一条要求你性格外向。

而且这些都是可以练的动作：写清楚、说清楚、演示清楚。练三次就有明显差别。

问这些新岗位会不会过两年就没了？

答　名字一定会变，位置不太可能变。

三年前这类岗位叫"低代码实施"，现在叫"AI 交付"或"智能体应用"。只要企业还在买工具回来用，就一定需要有人把它装起来、接上数据、教会同事。具体平台会换，但"最后一公里"这件事不会消失。

问我成绩一般，也没做过项目，现在开始来得及吗？

答　来得及，而且这可能是近几年最适合"普通水平"进场的一个窗口。

因为这些岗位看的东西，大家起点都差不多：名校生也没在本科课堂上练过写操作手册、也没给工厂做过 AI 工作流。这一类能力的差距，是靠实际做过几次拉开的，不是靠学校牌子。

上面第四步说的那份"作品包"（能跑的项目 + 操作手册 + 演示录屏），就是你现在最值得投入时间的东西。
