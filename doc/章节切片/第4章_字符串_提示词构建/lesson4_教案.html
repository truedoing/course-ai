四、核心讲解要点

1. 为什么用 f-string，而不是字符串拼接

# 拼接：变量一多就乱，还容易漏空格
prompt = "场景=" + scene + "；商品名=" + name + "；卖点=" + selling_point

# f-string：变量直接嵌在字符串里，可读、不易错（推荐）
prompt = f"场景={scene}；商品名={name}；卖点={selling_point}"

2. 字符串是不可变的

每拼一次都生成新字符串。对初学者而言，重点是"用 f-string 一次成型"，而不是反复 += 累加——后者既慢又易错。

3. 中英文标点与占位完整

提示词是给模型看的"契约"，标点、分号、字段顺序都要稳定。告诉学生：字段用 ； 分隔（全角），变量值直接嵌入，结尾的质量描述（真实摄影质感…）是固定文案。

五、学生练习任务（对应 lesson4_prompt.py）

  • 练习1（必做）：给定 name / selling_point / scene，用 f-string 写出 build_scene_prompt 函数体，并输出一条提示词。
  • 练习2（必做）：用 for 循环遍历 DEFAULT_SCENES，为一商品批量生成三条场景提示词（巩固第2/3章循环）。
  • 练习3（选做）：把循环封装成 make_all_prompts(name, selling_point)，返回提示词列表。

六、常见错误与纠偏

典型错误后果纠偏话术
漏写 f 前缀，写成 "场景={scene}"输出字面量 {scene}，没替换"忘记 f，花括号只是普通字符"
用 + 拼接却漏了空格/分号字段粘连，模型读歪"先写最终句子，再决定哪个词是变量"
字段顺序与母体不一致综合阶段接回时解析错位"顺序就是契约，今天定下综合阶段照用"
把 DEFAULT_SCENES 写成新名字与 manhua_studio.prompts 对不上"这个场景库名是母体定的，照搬"
