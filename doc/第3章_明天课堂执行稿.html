真实数据收尾怎么用

runs/production_log.csv 里是茶漏真实跑批结果：4 张全 done、0 failed、0 pending。它适合做「验证脚本能跑」的样板，但练不出三态判断——因为全是 done。

所以任务 2 需要一个混合状态的工单样本（比如「青瓷小铺一天接了 20 个 SKU 共 80 张图，其中 70 done / 6 failed / 4 pending」）。下面这份可直接粘贴进课堂，或我可以帮你生成 sample_batch.py / sample_batch.csv 放进项目：

# 课堂样本：一批混合状态的出图任务（第 5 章参数表会自动生成这种结构）
tasks = [
    {"name": "青花瓷茶漏", "scene": "中式茶席", "status": "done"},
    {"name": "青花瓷茶漏", "scene": "现代简约茶台", "status": "done"},
    {"name": "青瓷茶叶罐", "scene": "礼品盒", "status": "failed"},
    {"name": "白瓷盖碗",   "scene": "禅意书房", "status": "pending"},
    {"name": "青瓷茶漏",   "scene": "茶室礼盒", "status": "done"},
]

def count_status(tasks):
    done = failed = pending = 0
    for t in tasks:
        if t["status"] == "done":
            done += 1
        elif t["status"] == "failed":
            failed += 1
        else:
            pending += 1
    return {"done": done, "failed": failed, "pending": pending}

print(count_status(tasks))   # {'done': 3, 'failed': 1, 'pending': 1}
