manhua · 半成品走法（并跑）教师参考

并跑走法目标：不让学生碰管线逻辑，也能练到核心能力——「把业务需求翻译成 AI 能懂的指令」。 这是给 JS 班定的「AI 落地执行者」底层能力，不需要写代码就能长。

一、并跑学生要做的（改 prompt，不碰架构）

  • 写需求 / 选场景：改 manhua_studio/prompts.py 的 DEFAULT_SCENES（默认场景库）与 build_scene_prompt（出图规范），定义自己商品的场景与画风（练需求翻译 + 参数化思维）
  • 读 AI 输出：看终端打印的识别 JSON，核对商品名/卖点/场景提示词是否合理（练读懂 AI）
export UAPI_KEY=学生自己的 export ARK_API_KEY=学生自己的 # 想自定义场景/画风：先改 prompts.py 的 DEFAULT_SCENES / build_scene_prompt python -m manhua_studio --input input/我的商品.jpg
并跑默认改 prompts.py 调参（主动写需求）；S0 识别始终自动运行（豆包视觉生成商品名/卖点/建议场景），学生负责核对 JSON——两种都是「需求翻译」训练，前者主动写，后者批判读。

二、想再进一步：改 prompt 模板（仍是「调参」非「改架构」）

指向 manhua_studio/prompts.py，让学生改两处常量：

  • DEFAULT_SCENES：默认场景库列表，换成自己想要的场景
  • build_scene_prompt()：场景提示词模板（铁律：不写形容词，只放可填参数）
  • PLATFORM_SPECS：各平台尺寸/白底/文字占比规范——教「一致性控制」的源头
这一步练的是 prompt 工程 + 平台规范意识，仍不碰出图逻辑（generate.py），符合「并跑=AI 大量辅助，人做翻译与判断」。

三、给你的检查点（怎么判断学生真在并跑，不是躺平）

  • 能否说清：为什么选的这几个场景符合他选的平台规范（如淘宝 800x800、文字占比<20%）？
  • S0 识别时，能否指出 AI 识别错了一处（如把青花认成青瓷）并说清该回去改 prompts.py 里的哪段（场景名 / 提示词模板）？
  • 商品页里的卖点，是不是他自己写的、和他商品对得上？
与「三种走法」的衔接：并跑学生拿到的支撑物 = 上面的命令示例 + prompts.py 注释说明（已在包内）。 老师无需新建系统，只需把本页要点口头讲 5 分钟，再发已写好的完整代码包（含 env.example）给跟跑生、把 prompts.py 行号指给并跑生即可。 领跑生单独指到 adapters.py 加场景 / 修故障（见课程迭代计划 V5）。
