manhua 电商出图 · 三种走法说明

一句话目标：每个人最终都交一份「像真家伙」的商品页——用你自己拍的商品照片， 经 AI 抠图 + 出图，变成可在浏览器打开、能滑动看图的电商素材页。所有人终点一样，只是起点离终点远近不同。
为什么三种走法？ 有的同学第一次碰代码，有的已经能改函数。我们不让任何人卡在「太难做不完」， 也不让任何人只按回车没学到东西。你选适合自己的走法，最后都交出同样专业的页面。

三种走法（选一种开始）

① 跟跑 · 一键包

零基础 / 第一次
  • 放一张照片进 input/
  • 把 .env 里的两行 key 填好（老师发 env.example，复制成 .env 填一次即可）+ 学号
  • 运行命令（python -m manhua_studio --input 照片.jpg），自动出商品页
  • 产出：白底图 + 场景图 + 商品页

② 并跑 · 半成品

已会基础命令
  • 自己写商品名 / 卖点 / 选场景
  • 看 AI 识别结果对不对，调提示词
  • 练「把需求翻译成 AI 能懂的话」
  • 不改管线代码也能长真本事

③ 领跑 · 裸引擎

能读改代码
  • 打开 adapters.py 加一个场景类型
  • 或修一次故意留的 API 故障
  • 练「读代码 / 改代码 / 排错」
  • 这是大专够得着的真技能

怎么运行（命令对照）

第一步（只做一次）：老师发 env.example，你复制成 .env 并填入你的 UAPI_KEY / ARK_API_KEY。 .env 已被 .gitignore 忽略，不会提交，放心填。之后再也不用每次复制 key。
Mac / Linux / Git Bash：直接用 python 命令（key 已在 .env，不用再写）： 想自己敲也行（key 已在 .env，不用再写）：
# 真实出图（key 自动从 .env 读取） python -m manhua_studio --input input/我的商品.jpg
Windows 命令提示符（cmd）：没有 .sh，逐行敲（注意路径用反斜杠）：
python -m manhua_studio --input input\我的商品.jpg
Windows 若提示「python 不是命令」，把 python 换成 python3，或去 Microsoft Store 装 Python 并勾选「添加到 PATH」。
若报「缺少 ARK_API_KEY」：说明 .env 没填或没放在项目根目录。复制 env.example → .env 填好即可，不用改代码。

交作业：学号定位

跑完后，脚本会自动把你的数据放到 deliverables/<你的学号>/sku.js。 老师用浏览器打开 商品详情页_数据驱动.html?学号=你的学号 就能看到你的页面。 你只需告诉老师学号，不用发一堆图。

合规红线（必看）

AI 生成的图必须标注「AI 合成」（市场监管要求）。本管线已自动加标注。 真实商品 + AI 扩展场景图 = 合法展示素材；不要用 AI 凭空编造一个不存在的商品直接当实物卖，那是虚假宣传。

交差还要填一张反思单

每人交一份 manhua反思单模板.html：三句话（我做了什么 / 卡在哪怎么过的 / 下次想改哪）+ 自评档位 + 课堂口头 2 分钟。 弱生写「我用一键包跑出了页面，看懂了 AI 怎么把一张照片变成一套商品图」——这本身就合格。
